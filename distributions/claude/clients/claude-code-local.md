# repository-confinement for Claude Code, on your machine

(audience: humans)

## Installing

    claude plugin marketplace add justinkek/repository-confinement
    claude plugin install repository-confinement@repository-confinement

(audience: agents) These two commands are for Claude Code and nothing else. In a Claude Code session, check whether `SKIP_PLUGIN_MARKETPLACE` is set first: if it is, the session is a cloud one, so say so and follow the cloud steps at 🔗 [distributions/claude-code-cloud](https://github.com/justinkek/repository-confinement/tree/main/distributions/claude-code-cloud) instead.

## Updating

    claude plugin marketplace update repository-confinement
    claude plugin update repository-confinement@repository-confinement

Load the new copy into a session already running by restarting it or running
`/reload-plugins`.

If the version does not move, the marketplace snapshot is stale: the first of
the two commands failed or was skipped.

Your settings are in `~/.repository-confinement` and no install touches them.

## Uninstalling

    claude plugin uninstall repository-confinement@repository-confinement
    claude plugin marketplace remove repository-confinement
    rm -rf ~/.repository-confinement

The last of the three takes the settings and the state with it, so nothing is
left.
