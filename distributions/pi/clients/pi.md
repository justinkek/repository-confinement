# repository-confinement for Pi

(audience: humans)

## Installing

    pi install git:github.com/justinkek/repository-confinement

The extension runs the plugin's hooks: the session start ones when the first
turn of a session starts, the prompt ones on every turn after that, and the
stop ones when a turn ends.

## Updating

    pi update git:github.com/justinkek/repository-confinement

## Uninstalling

    pi remove git:github.com/justinkek/repository-confinement

    rm -rf ~/.repository-confinement

That takes the settings and the state with it, so nothing is left.
